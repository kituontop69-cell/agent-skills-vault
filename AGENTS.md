# Workspace skill usage

- Before starting a task, check the installed skills and apply every relevant skill.
- Combine multiple relevant skills when that improves correctness, safety, implementation quality, testing, or verification.
- Do not invoke unrelated skills just to use everything; keep the active workflow focused on the user's request.
- Prefer the workspace-local skills in `.opencode/skills/` and preserve their supporting files and references.
- Investigate first, make focused changes, and verify the result before reporting completion.
