## 🛠️ Integrated Execution Blueprints

### 1. The Autonomous Test-Driven Loop (`orch-loop-tdd`)
* **Trigger:** When building features without human oversight.
* **Mechanism:**
  1. Generate strict unit test asserting expected output.
  2. Confirm test fails in red state.
  3. Author minimal production code to reach green state.
  4. Perform non-breaking refactoring under test safety.

### 2. Multi-Agent Worktree Dispatch (`devfleet-swarm`)
* **Trigger:** 2+ independent engineering tasks.
* **Mechanism:**
  1. Clone separate git worktrees to prevent working tree collisions.
  2. Assign specialized agent roles (Architect, Implementer, Reviewer, Verifier).
  3. Aggregate results and verify unified test suite before merge.

### 3. Structural Code Health Gating (`codehealth-mcp`)
* **Trigger:** Before any commit or pull request.
* **Mechanism:**
  1. Inspect file complexity and function length.
  2. Reject changes that introduce cyclomatic spikes or code smells.
  3. Self-correct before human code review.
